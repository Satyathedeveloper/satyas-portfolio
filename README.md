# Satya Prasad Aripaka: Portfolio (React + TypeScript + Vite)

    npm install        # install dependencies
    npm run dev        # local dev server
    npm run build      # type-check and production build into dist/
    npm run preview    # preview the production build

Edit content in `src/data.ts` and `src/showcase.ts` (GEN ERP and Nutsby) (profile, experience, projects, skills, education). Add a project by adding one object to `projects`.
Replace `public/Satya_Prasad_Aripaka_Resume.pdf` when you update your resume.

## Deploy
- Vercel / Netlify: import the repo, build command `npm run build`, output directory `dist`.
- GitHub Pages: upload the contents of `dist/` (asset paths are relative).

When you have a domain, add a canonical link in `index.html` and a Sitemap line in `public/robots.txt`.

## What is Vite?
Vite is only the tool that runs your site locally (`npm run dev`) and bundles it for hosting (`npm run build`). Your code is React + TypeScript + plain CSS. You only need these commands: `npm install` (once), `npm run dev`, `npm run build`.
